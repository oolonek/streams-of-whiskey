# Dataset SMILES Discovery

This context screens tabular datasets for evidence of molecular structures expressed as SMILES, then inspects a pinpointed file when requested.

## Language

**SMILES evidence**:
A sampled string or group of strings whose content or labeling supports interpreting a field as molecular SMILES, rather than treating parser-valid incidental text as a match. A labeled field, explicit molecular notation, or corroborating distinct molecular strings can provide that evidence.
